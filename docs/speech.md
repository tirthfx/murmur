# Speech recognition

How recorded audio becomes text, on the device.

## Model

- Default: Whisper large-v3 turbo, compressed CoreML build (about 648 MB), run by WhisperKit in the helper. WhisperKit is pinned to exactly 1.1.1 in `native/helper-mac/Package.swift` (MIT licence).
- The manifest `packages/shared/src/speech-models.ts` lists every file with its size and SHA-256 at a pinned Hugging Face revision, plus the tokenizer files. It is generated by `node scripts/make-speech-manifest.mjs`; regenerate only to change the model.
- Files live in `~/Library/Application Support/Murmur/models/speech/whisperkit/<model id>/` (`model/` and `tokenizer/`). They are never committed.

## Download

```bash
npm run model:download -- speech
```

Downloads over HTTPS from huggingface.co only, hashes every file while writing, and moves the folder into place only when every file matches the manifest. Files already correct are kept, so the same command repairs a copy that fails its check. It needs Node 22.18 or later, because it runs the app's own TypeScript directly.

## Loading and checking

- When the helper becomes ready, main checks every file's size and SHA-256 (once per app run), then sends `transcribe.load` with the model and tokenizer folders. A missing model logs how to download it; a file that fails its check stops the load and logs which file.
- The helper loads only from those folders: WhisperKit's download is off, and a missing `tokenizer.json` is a load failure, because WhisperKit would otherwise fetch the tokenizer from the network. After the model is on disk, nothing reaches the network.
- The first load compiles the model for the Neural Engine and can take a few minutes; later loads are faster. Main allows 10 minutes. The helper keeps answering pings while it loads.

## Transcribing

- When a recording stops (and was not silent), main sends `transcribe.file` with the recording's path. The helper answers later with the text, the language, segments with times and a confidence from 0 to 1, the decode time and the audio length.
- One load or transcription runs at a time (`BUSY` otherwise). The helper allows 20 seconds of decoding per started 30 seconds of audio, then answers `TRANSCRIPTION_TIMEOUT`.
- Language: an empty list detects it; a single code forces it. Settings come in #13.
- The log shows the word count, never the words. Set `MURMUR_LOG_TRANSCRIPTS=1` before `npm run dev` to see the text while testing.
- Live text while speaking (`transcribe.start` and `transcribe.finish` with partials) comes later.

## Manual test

1. `npm run model:download`, `npm run build:helper`, then `MURMUR_LOG_TRANSCRIPTS=1 npm run dev`. Wait for `[speech] speech model ready`.
2. Hold Right Option, say a sentence, release. The terminal shows `[speech]`-ready timings and `[audio] transcribed … words` followed by `text: …`.
3. Turn off Wi-Fi and repeat: it still works.
4. Change one byte of a model file (for example `model/config.json`) and restart: the log says the model failed its checksum check and it is not loaded. `npm run model:download` repairs it.

## Languages

Settings, **Languages** (`speech.languages`): choose up to five, in order; the first is the
primary. A sixth is refused. With none chosen, the speech model detects the language on its
own.

- **One language:** the model is told that language.
- **Two to five:** the helper runs the model's language detection on the first 30 seconds,
  takes the chosen language it finds most likely (on a tie, the earlier one in the list),
  and then transcribes in that language. A language that was not chosen is never used.
- The tray's Languages menu makes a language the primary one, or switches to detection.
- A single language stored by an older build (`speech.language`) is carried over once.

### Hindi in Latin script

The profile **Mixed: Hindi in Latin script** (`hi-Latn`) is a choice in the same list, not a
separate model. It is recognised as Hindi or English; afterwards any Devanagari in the text
is written in Latin letters the way people type Hinglish ("ठीक है" becomes "theek hai"),
before cleanup. English words stay as they are. History keeps the text as heard (raw) and
as inserted (final). Removing the profile from the list switches it off; nothing else is
kept.

When the model writes an English word in Devanagari, it comes out spelled by sound. A cleanup
prompt for this profile can improve that later.
